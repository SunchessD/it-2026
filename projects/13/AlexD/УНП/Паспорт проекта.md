# ПАСПОРТ ПРОЕКТА

| Параметр | Описание |
| :--- | :--- |
| **Название проекта** | Веб-приложение для изучения и систематизации техник Brazilian Jiu-Jitsu (BJJ Academy) |
| **Заказчик проекта** | СПбПУ Петра Великого *(или ФИО преподавателя)* |
| **Команда проекта** | Дорошенко Александр |
| **Цели проекта** | 1. Обеспечение спортсменов структурированными знаниями о техниках BJJ.<br>2. Формирование индивидуального технического арсенала.<br>3. Создание условий для самостоятельного планирования тренировок. |
| **Задачи проекта** | 1. Разработать систему регистрации с подтверждением по email.<br>2. Создать энциклопедию техник с классификацией и GIF-анимациями.<br>3. Реализовать систему персональных коллекций с интерфейсом Drag-and-Drop.<br>4. Разработать инструмент планирования тренировок (месячный календарь) и дневник.<br>5. Реализовать административную панель управления контентом. |
| **Видение проекта** | Веб-приложение, где спортсмен может зарегистрироваться и получить доступ к базе техник BJJ. Пользователь создает личные коллекции с заметками и планирует график тренировок. Приложение помогает систематизировать знания и не забывать важные детали. |
| **Целевая аудитория** | Спортсмены, практикующие бразильское джиу-джитсу (от новичков до черных поясов), тренеры. |
