|Новый пользователь|
start
:Ввод данных;
:Нажатие «Зарегистрироваться»;

|Система|
:Валидация;

if (Данные корректны?) then (нет)
  :Сообщает о некорректности;
  ' Возврат к началу
  stop
  
else (да)
  :Создает неактивную сессию;
  :Генерирует код;
  :Ставит таймер;
  
  |Почтовый сервис|
  :Отправляет код;
  
  |Новый пользователь|
  :Вводит код;
  
  |Система|
  if (Код корректен?) then (нет)
    :Сообщает о некорректности кода;
    ' Возврат к вводу кода
    stop
    
  else (да)
    if (Время истекло?) then (да)
      :Сообщает об истечении;
      :Удаляет неактивную сессию;
      :Отправляет на ввод данных;
      ' Возврат к началу
      stop
      
    else (нет)
      :Создает активную сессию;
      :Направляет в личный кабинет;
      stop
    endif
  endif
endif
