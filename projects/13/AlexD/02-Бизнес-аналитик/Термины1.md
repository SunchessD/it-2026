## **Глоссарий терминов**


Садовод — зарегистрированный пользователь, ведущий коллекцию растений.

Новый пользователь — незарегистрированный пользователь, не имеющий доступ к работе в приложении.

Администратор — пользователь с расширенными правами для модерации контента.

Коллекция — совокупность растений конкретного садовода, сгруппированных по комнатам.

Растение — экземпляр комнатного растения в коллекции садовода с индивидуальным расписанием ухода.

Карточка растения — страница с информацией о конкретном растении: фото, вид, расписание, история ухода.

Расписание ухода — набор периодических задач для растения: полив (каждые N дней), подкормка (каждые N дней), пересадка (раз в N месяцев).

Действие ухода — единичное событие (полив, подкормка, пересадка, обрезка), зафиксированное в истории.

Комната — логическая группировка растений по местоположению (гостиная, кухня, балкон и т.д.).

Энциклопедия — справочный раздел с описанием видов комнатных растений и рекомендациями по уходу.

Вид растения — запись в энциклопедии с описанием, требованиями к свету/температуре/поливу, токсичностью.

Категория растений — классификация в энциклопедии.

Уведомление — сообщение пользователю о событии: напоминание о поливе, новый комментарий, ответ на запись.

Запись — публикация садовода в разделе сообщества (текст + фото).

Комментарий — ответ на запись другого садовода (поддерживает вложенность).

Система — серверная часть приложения: бизнес-логика, планировщик уведомлений, хранение данных.
