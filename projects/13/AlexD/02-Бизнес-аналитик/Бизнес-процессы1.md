## **Бизнес-процессы**

### **Акторы**

- Садовод — зарегистрированный пользователь, ведёт коллекцию растений и расписание ухода

- Новый пользователь — незарегистрированный пользователь, у когорого основные функции приложения не доступны

- Система — серверная часть приложения, отвечает за логику, уведомления, хранение данных

- Администратор — модерирует контент энциклопедии и сообщества

### **Группа 1: Регистрация и профиль**

**БП-1.1: Регистрация нового пользователя**

- Роли: Новый пользователь, Система

- Триггер: Новый пользователь заходит в приложение и инициирует процесс регистрации

- Шаги:
1) Новый пользователь заполняет форму (имя, email, пароль)
2) Валидация данных
3) Система создает учетную запись
4) Система уведомление об успешной регистрации и отправляет на указанный email
   

- Результат: Учётная запись создана и активна, письмо отправлено

  **БП-1.2: Аутентификация**

- Роли: Садовод, Система

- Триггер: Открытие страницы входа

- Шаги:

1) Ввод email и пароля
2) Проверка учётных данных
3) Генерация сессии
4) Перенаправление на дашборд

Результат: Пользователь авторизован, сессия активна.

**БП-1.3: Редактирование профиля**

- Роли: Садовод, Система

- Триггер: Открытие раздела «Профиль»

- Шаги:
1) Отображение текущих данных
2) Изменение полей (имя, аватар, город)
3) Валидация
4) Сохранение

- Результат: Профиль обновлён

### **Группа 2: Управление коллекцией растений**

**БП-2.1: Поиск растения в энциклопедии**

- Роли: Садовод, Система

- Триггер: Переход в раздел «Энциклопедия»

- Шаги:
1) Ввод названия или выбор категории
2) Поиск по базе
3) Отображение карточки растения (описание, условия, фото)

- Результат: Пользователь получает информацию по интересующему виду

**БП-2.2: Добавление растения в коллекцию**

- Роли: Садовод, Система

- Триггер: Нажатие «Добавить растение»

- Шаги:
1) Выбор вида из энциклопедии или ввод вручную
2) Загрузка фотографии
3) Настройка расписания ухода
4) Сохранение карточки

- Результат: Растение добавлено, расписание ухода активировано

**БП-2.3: Отметка о выполненном уходе**

- Роли: Садовод, Система

- Триггер: Напоминание о поливе / подкормке или ручной вызов

- Шаги:
1) Открытие карточки растения
2) Нажатие «Полито» / «Подкормлено» / «Пересажено»
3) Запись в историю ухода
4) Пересчёт следующей даты

- Результат: Действие зафиксировано, следующее напоминание обновлено

**БП-2.3: Просмотр истории ухода**

- Роли: Садовод, Система

- Триггер: Открытие карточки растения → вкладка «История»

- Шаги:
1) Запрос записей по растению
2) Отображение хронологии (дата, тип действия, заметки)

- Результат: Пользователь видит полную историю ухода за растением



### **Группа 3: Уведомления и системные процессы**

**БП-3.1: Получение уведомлений**

- Роли: Садовод, Система

- Триггер: Наступление события (время полива, новый комментарий, ответ)

- Шаги:
1) Формирование уведомления
2) Сохранение в базу
3) Push/email по настройкам пользователя

- Результат: Пользователь информирован о событии

**БП-3.2: Управление энциклопедией**

- Роли: Администратор, Система

- Триггер: Переход в панель администратора

- Шаги:

1) Создание нового вида растения (заполнение полей, загрузка фото)
2) Редактирование существующего вида
3) Удаление устаревшего вида

- Результат: Энциклопедия актуальна.
