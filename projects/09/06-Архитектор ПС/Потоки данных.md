# Потоки данных

Успешное чтение `session:{id}` продлевает срок бездействия до 30 минут. В сеансе лежат `account_id` и признак CSRF. Роль и организация каждый раз читаются из `account`.

Ключ идемпотентности принадлежит одному запросу. Он читается до записи и сохраняется только после успешного сохранения. Повтор с тем же ключом возвращает прежний результат и не создаёт вторую строку, не применяет статус, пороги или правку ещё раз.

## D-01. Регистрация организации

```mermaid
sequenceDiagram
    autonumber
    actor Guest as Гость
    participant Front as Приложение (Front)
    participant Back as Сервер (Back)
    participant Redis as Redis
    participant Db as База данных

    Guest->>Front: Название организации, имя, email, пароль
    Front->>Back: POST /api/register, Idempotency-Key
    Back->>Redis: GET idem:register:{key}
    alt Этот ключ уже выполнен
        Redis-->>Back: organization_id
        Back-->>Front: 200 OK, уже созданная организация
        Front-->>Guest: Успех и предложение войти
    else Новый запрос
        Back->>Back: Проверка полей
        alt Данные недопустимы
            Back-->>Front: 400 Bad Request
            Front-->>Guest: Ошибки, регистрация не завершена
        else Данные допустимы
            Back->>Db: email свободен, INSERT organization, account, пороги 2.00
            alt Email занят
                Db-->>Back: Конфликт уникальности
                Back-->>Front: 409 Conflict
                Front-->>Guest: Ошибка, организация не создана
            else COMMIT
                Db-->>Back: organization_id
                Back->>Redis: SET idem:register:{key}
                Back-->>Front: 201 Created
                Front-->>Guest: Успешная регистрация и предложение войти
            end
        end
    end
```

## D-02. Вход и выход

```mermaid

            Back-->>Front: 200 OK, cookie сеанса и CSRF
            Front-->>Guest: Главное меню своей организации
        else Email неизвестен или пароль неверен
            Back->>Redis: INCR login:fail:{email} по lower(email)
            Back-->>Front: 401 Unauthorized
            Front-->>Guest: Сообщение «Неверный логин»
        end
    end
```

## D-03. Присоединение по коду

```mermaid
sequenceDiagram
    autonumber
    actor Guest as Гость
    participant Front as Приложение (Front)
    participant Back as Сервер (Back)
    participant Redis as Redis
    participant Db as База данных

    Guest->>Front: Код приглашения
    Front->>Back: POST /api/invitations/check
    Back->>Db: Найти код и признак revoked
    alt Код не найден или отозван
        Db-->>Back: Нет действующего кода
        Back-->>Front: 404 Not Found или 410 Gone
        Front-->>Guest: Код недействителен
    else Код действует
        Db-->>Back: organization_id
        Back-->>Front: 200 OK
        alt Учётная запись уже есть
            Guest->>Front: Email и пароль
            Front->>Back: POST /api/invitations/accept
            Back->>Redis: GET login:fail:{email} по lower(email)
            alt Пауза после 10 отказов за 5 минут ещё идёт
                Back-->>Front: 429 Too Many Requests
                Front-->>Guest: Повтор не раньше чем через минуту
            else Проверка пароля
                Back->>Db: Учётная запись по lower(email), сверка Argon2id
                alt Пароль неверен
                    Back->>Redis: INCR login:fail:{email} по lower(email)
                    Back-->>Front: 401 Unauthorized
                    Front-->>Guest: Ошибка входа
                else Пароль совпал
                    Back->>Db: Повторно прочитать код и организацию в транзакции
                    alt Код уже отозван
                        Back->>Db: ROLLBACK
                        Back-->>Front: 410 Gone
                        Front-->>Guest: Присоединение не выполнено
                    else Запись другой организации
                        Back->>Db: ROLLBACK
                        Back-->>Front: 409 Conflict
                        Front-->>Guest: Принадлежность прежняя
                    else Запись этой организации
                        Back->>Db: UPDATE role = analyst, organization_id без изменений
                        Db-->>Back: COMMIT
                        Back->>Redis: SET session:{id}, account_id и CSRF, TTL 30 минут
                        Back-->>Front: 200 OK, cookie сеанса
                        Front-->>Guest: Вход, роль аналитика, организация прежняя
                    end
                end
            end
        else Новая учётная запись
            Guest->>Front: Имя, email, пароль
            Front->>Back: POST /api/invitations/accept, Idempotency-Key
            Back->>Redis: GET idem:accept:{key}
            alt Этот ключ уже выполнен
                Redis-->>Back: account_id
                Back->>Redis: SET session:{id}, account_id и CSRF, TTL 30 минут
                Back-->>Front: 200 OK, cookie уже созданной записи
                Front-->>Guest: Повтор не создаёт вторую учётную запись
            else Новый запрос
                Back->>Back: Проверка полей
                alt Данные недопустимы
                    Back-->>Front: 400 Bad Request
                    Front-->>Guest: Ошибки анкеты
                else Данные допустимы
                    Back->>Db: Код ещё действует, email свободен, INSERT аналитика
                    alt Код отозван или email занят
                        Back->>Db: ROLLBACK
                        Back-->>Front: 409 Conflict или 410 Gone
                        Front-->>Guest: Отказ, прежние аналитики на месте
                    else COMMIT
                        Db-->>Back: account_id
                        Back->>Redis: SET idem:accept:{key}
                        Back->>Redis: SET session:{id}, account_id и CSRF, TTL 30 минут
                        Back-->>Front: 201 Created, cookie сеанса
                        Front-->>Guest: Успешное присоединение
                    end
                end
            end
        end
    end
```

## D-05. Изменение профиля

```mermaid
sequenceDiagram
    autonumber
    actor User as Администратор или аналитик
    participant Front as Приложение (Front)
    participant Back as Сервер (Back)
    participant Redis as Redis
    participant Db as База данных
    participant Mail as Почта

    User->>Front: Новое имя или новый пароль, «Сохранить»
    Front->>Back: PATCH /api/profile, cookie, CSRF, Idempotency-Key
    Back->>Redis: GET session:{id}
    Redis-->>Back: account_id
    Back->>Redis: GET idem:{account_id}:{key}
    alt Этот ключ уже выполнен
        Redis-->>Back: прежний результат
        Back-->>Front: тот же ответ
        Front-->>User: Повтор не меняет имя и пароль ещё раз
    else Новый запрос
        Back->>Db: Роль, email и organization_id
        alt Данные недопустимы
            Back-->>Front: 400 Bad Request
            Front-->>User: Ошибки, прежние имя и пароль на месте
        else Меняется имя
            Back->>Db: UPDATE full_name
            Db-->>Back: Строка обновлена
            Back->>Redis: SET idem:{account_id}:{key}
            Back-->>Front: 200 OK, имя и email
            Front-->>User: Обновлённый профиль
        else Меняется пароль
            Back->>Back: Argon2id нового пароля
            Back->>Redis: SET pwd:{account_id}, код и хэш, TTL 10 минут
            Back->>Mail: Письмо с кодом на email учётной записи
            Back->>Redis: SET idem:{account_id}:{key}
            Back-->>Front: 200 OK, пароль ещё не изменён
            Front-->>User: Запрос кода из письма
            User->>Front: Код из письма, «Подтвердить»
            Front->>Back: POST /api/profile/password, cookie, CSRF, Idempotency-Key подтверждения, код
            Back->>Redis: GET session:{id}
            Redis-->>Back: account_id
            Back->>Redis: GET idem:{account_id}:{confirm}
            alt Этот ключ уже выполнен
                Redis-->>Back: пароль уже сохранён
                Back-->>Front: 200 OK, имя и email
                Front-->>User: Обновлённый профиль
            else Проверка кода
                Back->>Redis: GET pwd:{account_id}
                alt Код неверен или срок истёк
                    Back-->>Front: 400 Bad Request
                    Front-->>User: Пароль не сохранён, ошибка кода
                else Код верный
                    Back->>Db: UPDATE password_hash хэшем из Redis
                    Back->>Redis: DEL pwd:{account_id}
                    Back->>Redis: SET idem:{account_id}:{confirm}
                    Back-->>Front: 200 OK, имя и email
                    Front-->>User: Обновлённый профиль
                end
            end
        end
    end
```

## D-11. Разбор аномалии

```mermaid
sequenceDiagram

        Front-->>User: Статус open, запроса сохранения нет

        User->>Front: «Подтверждена» или «ложная», «Сохранить»

        Back->>Db: Роль и organization_id

            Back-->>Front: 200 OK, прежний результат

                Db-->>Back: Строки нет
                Back-->>Front: 404 Not Found
                Front-->>User: Карточка не сохранена

                    Db-->>Back: Новый status и version
                    Back->>Redis: SET idem:{account_id}:{key}
                    Back-->>Front: 200 OK
                    Front-->>User: Карточка с сохранённым статусом
                else Версия уже другая
                    Back->>Db: Прочитать статус этой организации
                    Db-->>Back: Текущая карточка
                    Back-->>Front: 409 Conflict и этот статус
                    Front-->>User: Конфликт, виден уже записанный статус
                end
            end
        end
    end
```

```mermaid
sequenceDiagram
    autonumber
    actor Admin as Администратор

    else Администратор
```

```mermaid
            Back-->>Front: 202 Accepted, уже принятая партия

        else Новый запрос
            Back->>Back: Размер, UTF-8, число строк, пустые тексты

                Back-->>Front: 202 Accepted, обработка не завершена

                Worker->>Redis: BRPOP queue:import
                Redis-->>Worker: import_id

                loop Каждый текст партии
                    Worker->>Model: Вызов библиотеки, строка отзыва
                    Model-->>Worker: позитивная, нейтральная или негативная
                end
                Worker->>Worker: Окно объекта: конец — полночь UTC после суток самого позднего датированного отзыва партии, начало на 24 часа раньше, конец не входит
                Worker->>Worker: Спам датированных отзывов окна: полное совпадение после схлопывания пробелов, без учёта регистра
                alt Сбой до COMMIT

                else Тональность не проставлена
                    Worker->>Db: COMMIT failed, failure_reason, started_at и finished_at, тональность пустая
                else Успех
```
