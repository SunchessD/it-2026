# Веб-сервис учёта и анализа личных расходов

Юдин Пётр Павлович, группа 5040102/60201. Проектная команда 16.

Сервис хранит личные расходы пользователя, распределяет их по категориям и показывает сводку за выбранный месяц. Первая версия рассчитана на ручной ввод расходов в рублях.

## Технологии

Для сервиса выбраны Django с серверными HTML-шаблонами, PostgreSQL и Redis для кэша месячной сводки.

В [презентации Redis](../../presentations/17/README.md) используется отдельный консольный пример на Python и SQLite. Он показывает работу кэша, но не реализует регистрацию, веб-интерфейс и остальные функции этого проекта.
