# Термины

| Термин | Значение в проекте |
| --- | --- |
| Гость | Посетитель без действующей сессии. Доступны регистрация и вход. |
| Пользователь | Владелец учётной записи, личных категорий и расходов. |
| Расход | Одна запись о трате: положительная сумма, дата, категория и необязательный комментарий. |
| Категория | Принадлежащая пользователю группа расходов. Каждый расход относится к одной категории. |
| Архивная категория | Категория, доступная в истории и сводках, но недоступная для новых расходов. |
| Период | Включительный диапазон дат в фильтре списка расходов. |
| Месяц сводки | Календарный месяц в формате `YYYY-MM`. При запросе к БД используется интервал от первого дня месяца включительно до первого дня следующего месяца исключительно. |
| Сводка | Рассчитанные по расходам итог и распределение по категориям за месяц. Самостоятельной таблицы сводок в PostgreSQL нет. |
| Копейки | Целочисленная единица хранения суммы. 80,00 рубля хранятся как 8 000 копеек. |
| Сессия | Состояние входа пользователя. Идентификатор передаётся в cookie, данные сессии хранятся средствами Django в PostgreSQL. |
| Основная БД | PostgreSQL, где хранятся исходные расходы, категории, учётные записи и ревизии. |
| Кэш | Временная копия рассчитанной месячной сводки в Redis. Её потеря не удаляет исходные расходы. |
| Cache-aside | Приложение сначала проверяет кэш, а при промахе рассчитывает результат по основной БД и сохраняет его в кэше. |
| Попадание / промах | Наличие пригодного результата в кэше / необходимость получить результат из основной БД. |
| TTL | Срок жизни ключа. Для сводки первоначально принимается 60 секунд. TTL ограничивает хранение, но сам не узнаёт об изменении расходов. |
| Ревизия | Неотрицательный счётчик изменений данных одного пользователя. Включается в ключ сводки и увеличивается при изменениях расходов и категорий. |
| Инвалидация | Прекращение использования устаревшего результата. В проекте достигается сменой ревизии и, следовательно, ключа. |
| Expiration | Удаление ключа после истечения его срока жизни. |
| Eviction | Вытеснение ключей из Redis при достижении ограничения памяти согласно выбранной политике. |
| Транзакция БД | Группа изменений PostgreSQL, которая фиксируется целиком или отменяется. Изменение расхода и его ревизии входит в одну такую транзакцию. |
| Консольный пример | Программа для доклада Redis на Python и SQLite. Она иллюстрирует кэширование, но не является готовым веб-сервисом. |
